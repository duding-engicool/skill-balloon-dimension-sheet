# 一般公差声明提取与未注公差参考表

提取一般公差声明、推导「最终公差」时加载本文件。

## ⚠️ 使用前置声明（必读，防幻觉）

**本文件第 2、3、4 节的数值表为待原文核对的参考表，尚未与 GB/T 1804-2000 / GB/T 1184-1996 标准原文逐值比对。**

由此推导出的「最终公差」：

- 公差来源列必须填 `参考表(待核对)`，不得填 `一般公差`
- 该尺寸必须列入交付物汇总 Sheet 的**待确认清单**
- 若项目对公差有严格用途（如客户验收、PPAP 提交），**必须先拿标准原文核对后再填值**

禁止默认套用：图纸未声明一般公差时，一律填 `待确认`、来源填 `未声明`，不自动选 f/m/c/v 任何等级。

## 1. 一般公差声明的检测位置（逐处检查，共 4 处）

1. **标题栏**：如"未注公差按 GB/T 1804-m"
2. **技术要求**：如"1. 未注公差尺寸的极限偏差按 GB/T 1804-2000 m级；2. 未注形位公差按 GB/T 1184-K"
3. **明细栏备注**：如"未注公差按 ISO 2768-mK"
4. **修订栏/图幅角落注释**：如"一般公差按公司标准 Q/XXX-2023"

解析字段：标准号（GB/T 1804、GB/T 1184、ISO 2768、ASME Y14.5、公司标准）、等级（f/m/c/v、H/K/L）、适用范围（线性/角度/形位）。

**英制图纸禁止套用 GB/T 1804 / ISO 2768**，改取原图 "UNLESS OTHERWISE SPECIFIED" 栏；数值不换算，单位列填 inch。

**跨页/跨图冲突时不自动决定**，输出冲突清单交用户确认。

## 5. 边界处理规则

- 配合代号（H7、g6）查专用表，**不套一般公差**
- 螺纹（M10-6g）查螺纹标准，**不套一般公差**
- 圆角、倒角是否适用一般公差需确认公司标准，默认标"待确认"
- 尺寸分段开闭区间必须正确

## 6. 明确禁止采用的来源

**GB/T 14486-2008（塑料件尺寸公差 MT1~MT7）**：该标准为付费标准，公开渠道流传的数值表互相矛盾（多个来源不一致，且部分来源标明为 AI 生成）。
**一律不得采用任一来源填值**，「最终公差」填 `MT6 待查表`，并在备注给出可验证的备用口径（如标题栏勾选的 GB/T 1804-m）。

## 7. 公差优先级链（每个尺寸必须落到一条）

1. **显式公差** → 用显式，来源 `图纸标注`
2. **配合代号/螺纹/齿轮专用标准** → 查专用表，来源 `配合公差` / `螺纹标准`
3. **未注尺寸 + 图纸已声明一般公差** → 查声明，来源 `一般公差`
4. **未注尺寸 + 图纸未声明** → 查本参考表，来源 `参考表(待核对)`，列入待确认
5. **类型无法判断** → `待确认`，来源 `未声明`
