# 气泡规格 · 避让校验 · 量具与检验规则

定气泡尺寸、算单位、做避让校验、推量具与检验频次时加载本文件。

## 1. 单位换算（1mm = 2.8346pt）

| 项 | 毫米 | 磅(pt) |
|----|------|--------|
| 外圈直径 | 6mm | 17.0pt（**R = 8.5pt**） |
| 外圈直径（编号 ≥100） | 8mm | 22.7pt（R = 11.3pt） |
| 数字字号 | 4mm | 11.3pt（最小 3.5mm = 9.9pt） |
| 描边线宽 | 0.35mm | ≈1.0pt |
| 圆心最小间距 | 2R+1 | Ø6mm 时 **18pt** |

Ø6mm 圆内可容纳 2 位数（≤99），这是常态。编号到 3 位数时直径放大到 8mm，仍为圆圈，并在交付说明中写明该偏离。

## 2. 气泡样式（统一，不允许变化）

- 一律**红色圆圈 + 数字**，描边不填充（填充会遮住底图）
- 描边、数字、引线全部红色；主色 `#C8102E`
- **唯一允许的变化是整体尺寸**（直径/字号），禁止改变形状
- 特性分类不在图上表达，不用星形/三角/虚线

## 3. 避让与引线校验（4 项，交付前必查）

1. 气泡圆盘与所有尺寸文本包围盒（外扩 2mm）**不相交**
2. 引线采样点**不落在任何非自身文本包围盒**内（本条尺寸自身 bbox 豁免）
3. 引线到其他气泡圆心的**点-线段距离** > R+2 —— **不要用包围盒判，会大量误报**
4. 气泡圆心间距 ≥ 2R+1

**布局顺序**：先找图纸空白区/视图外围放气泡，不是先压在尺寸上再避让。
气泡与尺寸文本至少留 2mm 间隙；空间不足移到空白区。

**掩膜必须用 span 级 bbox**（PyMuPDF 用 `page.get_text("dict")`），
不能用 `get_text("blocks")` —— 旋转文字会把 block 撑成大块，导致大面积误阻挡。
矢量绘制的 Ø 等符号要手工补进掩膜。

**自动布局的诚实预期**：自动结果必有 1/5 位置不理想（引线过长、压图形）。
本技能的解法不是继续调算法，而是**让用户在网页里拖拽 + 程序化校验**，不指望全自动。

## 5. 特性分类与检验规则（建议值，须用户确认）

**特性分类判定顺序**：图纸特性符号（★/△/∇ 等）> 客户指定清单 > 技术要求声明 > 默认"一般"。

| 分类 | 缩写 | 定义 | 默认检验类别 | 默认频次 |
|------|------|------|-------------|---------|
| 关键特性 | CC | 影响安全、法规、核心功能 | 首检 + 完工检 | 100% 检验，SPC 监控 |
| 重要特性 | SC | 影响功能、装配、客户满意度 | 完工检 | 加严抽检，SPC 监控 |
| 一般特性 | — | 常规尺寸 | 完工检 | 常规抽检 |

**AQL 数值不默认套用**。频次列只写"常规抽检/加严抽检/100%"，具体抽样方案（GB/T 2828.1 检验水平与 AQL）填"待确认"，由用户按公司标准定。
